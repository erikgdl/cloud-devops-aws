# Cloud DevOps

A capa “Anatomia de um deploy” abre o trabalho com uma vista axonométrica do fluxo entre o registro de imagens, o host Ubuntu e a aplicação HTTP.

A página usa o azul para traçar a infraestrutura e o verde-lima para indicar o percurso da imagem e as ações disponíveis. Os capítulos ocupam pelo menos a altura da tela. Os blocos aparecem ao entrar na área de leitura. A preferência de movimento reduzido permite ler a página em seu estado estático.

O quadro de arquitetura acompanha dois caminhos até o Docker Compose. O quadro de portabilidade mostra como o inventário identifica dois destinos para o playbook Ansible. O encerramento apresenta a defesa N2.

A paleta e as famílias tipográficas ficam em `src/styles/tokens.css`. O metadado de tema e o favicon usam as mesmas cores fora da árvore React.
